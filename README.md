# OSOS : un projet d'analyse de réseau d'acteurs

Cette étude a comme objectif d'étudier les dynamiques actuelles entre _open science_ et Open Source.

Suite à la participation d'Inno³ à [CHAOSScon](https://chaoss.community/chaosscon-2020-eu/) et sa présence à la devroom "Open Research Tools and Technologies" de [FOSDEM](https://fosdem.org/2020/schedule/track/open_research_tools_and_technologies/), ce projet de recherche a pris comme point de départ l’analyse du réseau de suivi Twitter des participants de ces deux événements-espaces afin d'explorer l'écosystème qui se forme à la croisée de l'_open science_ et de l'Open Source en 2020.

Ce projet fait lui-même l'objet d'une démarche de science ouverte et met à disposition la documentation relative au processus de recherche, les fichiers de données collectées, le code utilisé pour les traiter ainsi que les visualisations produites.

## Repositories

- `Code` : contient les Jupyter Notebook utilisés pour traiter les données
- `Project_Files` : contient les données structurées en fichiers csv 
- `Viz` : contient les visualisations du réseau
- `twarc_data` : contient les données brutes collectées de Twitter en format jsonl et txt

## Documentation

Le détail des commandes utilisées pour la récolte des données se trouve dans le fichier `About_twarc_data_file.md` dans le `twarc_data`

## Bibliographie

Une bibliographie indicative est consultable sur Zotero.org : [[I3-Recherche] Social Network Analysis](https://www.zotero.org/groups/2408085/master_d2sn_2020/library)

# OSOS : an actor-network analysis project

This project aims to study the current dynamics bewteen open science and open source.

Following Inno³'s presentation at [CHAOSScon](https://chaoss.community/chaosscon-2020-eu/) and presence at the [FOSDEM *Open Research Tools and Technologies devroom*](https://fosdem.org/2020/schedule/track/open_research_tools_and_technologies/), this project starts by analyzing the Twitter follow graph of particpants from these two conference spaces in order to explore the actors who work at the crossroads of open source and open science in 2020.

This project is itself an experiment in open science and provides open access to research documentation, collected data, and code used to produce the visual representations of the network.

## Repositories

- `Code` : contains the Jupyter Notebooks used for structuring the collected data 
- `Project_Files` : contains the data in csv structure 
- `Viz` : contains the network visuals
- `twarc_data` : contains the raw data collected from Twitter in jsonl and txt format

## Documentation

The commands used to collect data from Twitter are detailed in the file `About_twarc_data_file.md` in the `twarc_data` repo
